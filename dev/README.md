# Materiais de desenvolvimento

Esta pasta concentra tudo que **não precisa ficar na raiz** do aplicativo:

- `docs/`: documentação e anotações técnicas
- `tests/`: testes do shell Office Tools
- `padroniza_tests/`: testes recebidos com o Padroniza
- `examples/`: arquivos de exemplo
- `tools/`: scripts auxiliares

A ideia é deixar a pasta principal mais limpa para uso diário.
